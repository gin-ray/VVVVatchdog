# VVVVatchdog

Система мониторинга (Watchdog) для мультимедийных инсталляций: автоматический перезапуск приложений при зависании или падении, настройки в XML, UI на VL.ImGUI.

**Реализация** — в .vl файлах (VVVV Gamma), обычно в папке `vvvv/`.  
**Документация** — в [docs/](docs/): ТЗ, архитектура (Model + Runtime + UIDrawer), референсы DSG и Remoter. Начни с [docs/README.md](docs/README.md).
