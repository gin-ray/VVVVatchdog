# Скетчи интерфейса

Эта папка содержит скетчи, макеты и референсы интерфейса для VVVVatchdog.

## Назначение

Скетчи используются как референс при разработке UI компонентов на VL.ImGUI.

## Форматы

Рекомендуемые форматы для скетчей:
- PNG, JPG - для растровых изображений
- SVG - для векторных изображений (если доступно)

## Примечание

Скетчи хранятся в репозитории и версионируются вместе с кодом для отслеживания эволюции дизайна интерфейса.
