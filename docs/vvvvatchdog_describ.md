WATCHDOG (Система мониторинга)
1. Общие сведения (Overview)
Назначение блока: Локальный агент контроля работоспособности визуального ПО на медиа-серверах.
Цели и задачи: Автоматическое восстановление работы инсталляции после программных сбоев или зависаний.
Контекст в проекте: EXE-приложение, развернутое на каждой клиентской машине с визуальным движком.
2. Функциональные требования (Functional Requirements)
Ключевые возможности:
Liveness Check: Мониторинг наличия процесса в системе по его имени/PID.
Heartbeat Check: Детекция зависаний через анализ входящего OSC-потока от визуального движка.
Telemetry: Отображение FPS и нагрузки (GPU/RAM) наблюдаемого ПО в реальном времени.
Tray Mode: Работа в фоновом режиме с быстрым доступом через системный трей.
3. Архитектура и технический стек (Architecture & Tech Stack)
Стек технологий: VVVV Gamma 7.0+, .NET (C#).
Используемые библиотеки (Nugets):
VL.ImGui / VL.Avalonia: Отрисовка Dashboard.
VL.IO.OSC: Прием Heartbeat и телеметрии.
System.Diagnostics.Process: Управление жизненным циклом приложений Windows.
System.Windows.Forms: Интеграция с системным треем.
Компоненты системы:
WatchdogService: Ядро системы (конечный автомат).
TDPayload: Структура данных для хранения телеметрии.
SystemInfoProvider: Модуль идентификации хоста (Hostname, IP).
4. Логика работы и потоки данных (Data Flow & Logic)
/ СХЕМА: Алгоритм Watchdog (Check Process -> Check OSC Heartbeat -> Decision: Restart/Idle) /
Программа работает в непрерывном цикле, выполняя проверки 60 раз в секунду:
Проверка процесса: Если процесс не найден через GetProcessesByName, инициируется Start.
Контроль зависаний: Если OSC-сообщения не поступают более заданного таймаута (Stopwatch), процесс принудительно завершается (Kill) для последующего перезапуска.
Пауза (Manual Control): Возможность временной блокировки действий Watchdog для проведения технических работ.
5. Интерфейс и управление (UI/UX)
Dashboard (ImGui): Окно со статусом (Running/Frozen), графиком FPS и логом событий.
Tray Manager: Иконка в трее с контекстным меню (Show, Force Restart, Pause, Quit).
Визуализация: Цветовая индикация (Зеленый — OK, Желтый — Pause, Красный — Restart/Error).
6. Безопасность и отказоустойчивость (Reliability)
Cooldown: Защита от «циклической перезагрузки» при фатальных ошибках запуска.
Deployment Script: Использование prepare_machine.ps1 для настройки окружения Windows (автозапуск, электропитание).
Централизация (Перспектива): Архитектура готова к передаче данных о статусе на центральный сервер для общего мониторинга всей сети.
