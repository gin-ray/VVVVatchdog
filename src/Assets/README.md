# Assets

Эта папка содержит ресурсы приложения: иконки, дефолтные конфигурации и другие статические файлы.

## Содержимое

- **Иконки**: Иконки для системного трея и UI элементов
- **Дефолтные конфиги**: Шаблоны конфигурационных файлов XML
- **Прочие ресурсы**: Любые другие статические файлы, необходимые для работы приложения

## Примечание

Файлы ресурсов будут добавлены по мере необходимости в процессе разработки.
