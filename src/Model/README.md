# Model

Эта папка содержит определения моделей данных (C# Records) и базовую логику работы с данными.

## Модели данных

- **AppConfig**: Конфигурация отслеживаемого приложения
  - Имя приложения
  - Путь к исполняемому файлу
  - Аргументы запуска
  - Включен ли watchdog
  - Таймаут ожидания

- **AppState**: Текущее состояние приложения
  - Статус процесса (Running, Frozen, Stopped, Restarting, Error)
  - PID процесса
  - Время работы (Uptime)
  - Количество перезапусков
  - Последнее событие

- **WatchdogModel**: Корневая модель, содержащая все приложения и глобальные настройки

- **GlobalConfig**: Глобальные настройки watchdog
  - Максимальное количество перезапусков в час
  - Интервал проверки процессов
  - Таймаут graceful shutdown
  - Настройки OSC

- **ProcessStatus**: Enum со статусами процесса

## Примечание

Файлы `.vl` с определениями Records будут созданы через редактор VVVV Gamma. Здесь будут храниться только описания и документация.
