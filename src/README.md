# Структура исходного кода VVVVatchdog

Эта папка содержит весь исходный код проекта, организованный по архитектуре MVVM.

## Структура папок

### Model/
Определения моделей данных (C# Records) и базовая логика работы с данными.

**Модели данных:**
- **AppConfig**: Конфигурация отслеживаемого приложения
  - Имя приложения
  - Путь к исполняемому файлу
  - Аргументы запуска
  - Включен ли watchdog
  - Таймаут ожидания

- **AppState**: Текущее состояние приложения
  - Статус процесса (Running, Frozen, Stopped, Restarting, Error)
  - PID процесса
  - Время работы (Uptime)
  - Количество перезапусков
  - Последнее событие

- **WatchdogModel**: Корневая модель, содержащая все приложения и глобальные настройки

- **GlobalConfig**: Глобальные настройки watchdog
  - Максимальное количество перезапусков в час
  - Интервал проверки процессов
  - Таймаут graceful shutdown
  - Настройки OSC

- **ProcessStatus**: Enum со статусами процесса

### ViewModel/
Логика представления (ViewModel) в архитектуре MVVM.

**Компоненты:**
- **WatchdogViewModel**: Главный ViewModel для управления состоянием всех отслеживаемых приложений
  - Управление списком приложений
  - Реактивные каналы для обновления UI
  - Логика перезапуска с учётом ограничений (защита от boot loop)
  - Обработка событий от ProcessHelper

- **AppViewModel**: ViewModel для управления состоянием одного приложения
  - Отслеживание состояния конкретного процесса
  - Обработка событий запуска/остановки
  - Управление перезапусками

**Технологии:**
- Reactive Extensions (Observable/Channels) для реактивного управления состоянием
- Интеграция с Model и Utils слоями
- Связь с View через реактивные потоки данных

### View/
UI компоненты, реализованные на VL.ImGUI.

**Компоненты интерфейса:**
- **MainWindow**: Главное окно приложения
  - Контейнер для всех виджетов
  - Управление размерами и позицией окна

- **DashboardWidget**: Виджет со списком отслеживаемых приложений
  - Отображение списка приложений
  - Статусы процессов (Running, Frozen, Stopped, Restarting, Error)
  - Индикаторы состояния
  - Кнопки управления (запуск, остановка, перезапуск)

- **LogWidget**: Виджет консоли логов
  - Отображение событий в реальном времени
  - Фильтрация по типу событий
  - Прокрутка логов

- **SettingsEditor**: Редактор конфигурации
  - Редактирование настроек приложений
  - Добавление/удаление приложений
  - Сохранение/загрузка конфигурации

- **SystemTray**: Интеграция с системным треем
  - Иконка в трее
  - Контекстное меню
  - Сворачивание/разворачивание окна

**Технологии:**
- **VL.ImGUI**: Библиотека для создания UI в VVVV Gamma
- Реактивная связь с ViewModel через Observable/Channels

### Utils/
Утилиты и вспомогательные сервисы.

**Компоненты:**

#### XMLSerializer
Сериализация и десериализация конфигурации в XML формат.
- Сохранение конфигурации в файл
- Загрузка конфигурации из файла
- Валидация структуры XML

#### ProcessHelper
Утилиты для работы с процессами Windows.
- **GetProcessesByName**: Получение списка процессов по имени
- **IsProcessResponding**: Проверка, отвечает ли процесс (не завис ли)
- **StartProcess**: Запуск процесса с указанными аргументами
- **GracefulShutdown**: Попытка корректного завершения процесса
- **KillProcess**: Принудительное завершение процесса
- **GetProcessInfo**: Получение информации о процессе (PID, Uptime, CPU, RAM)

#### OSCService
Сервис для OSC коммуникации (VL.IO.OSC).
- Инициализация OSC сервера
- Отправка статусов процессов внешним системам
- Приём команд управления (запуск, остановка, перезапуск)
- Обработка OSC сообщений

### Assets/
Ресурсы приложения: иконки, дефолтные конфигурации и другие статические файлы.

**Содержимое:**
- **Иконки**: Иконки для системного трея и UI элементов
- **Дефолтные конфиги**: Шаблоны конфигурационных файлов XML
- **Прочие ресурсы**: Любые другие статические файлы, необходимые для работы приложения

## Примечание

Файлы `.vl` с реализацией будут созданы через редактор VVVV Gamma. В папках хранятся только описания и документация.
