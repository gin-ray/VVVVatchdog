# Utils

Эта папка содержит утилиты и вспомогательные сервисы.

## Компоненты

### XMLSerializer
Сериализация и десериализация конфигурации в XML формат.
- Сохранение конфигурации в файл
- Загрузка конфигурации из файла
- Валидация структуры XML

### ProcessHelper
Утилиты для работы с процессами Windows.
- **GetProcessesByName**: Получение списка процессов по имени
- **IsProcessResponding**: Проверка, отвечает ли процесс (не завис ли)
- **StartProcess**: Запуск процесса с указанными аргументами
- **GracefulShutdown**: Попытка корректного завершения процесса
- **KillProcess**: Принудительное завершение процесса
- **GetProcessInfo**: Получение информации о процессе (PID, Uptime, CPU, RAM)

### OSCService
Сервис для OSC коммуникации (VL.IO.OSC).
- Инициализация OSC сервера
- Отправка статусов процессов внешним системам
- Приём команд управления (запуск, остановка, перезапуск)
- Обработка OSC сообщений

## Примечание

Файлы `.vl` с реализацией утилит будут созданы через редактор VVVV Gamma. Здесь будут храниться только описания и документация.
