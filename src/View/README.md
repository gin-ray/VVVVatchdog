# View

Эта папка содержит UI компоненты, реализованные на VL.ImGUI.

## Компоненты интерфейса

- **MainWindow**: Главное окно приложения
  - Контейнер для всех виджетов
  - Управление размерами и позицией окна

- **DashboardWidget**: Виджет со списком отслеживаемых приложений
  - Отображение списка приложений
  - Статусы процессов (Running, Frozen, Stopped, Restarting, Error)
  - Индикаторы состояния
  - Кнопки управления (запуск, остановка, перезапуск)

- **LogWidget**: Виджет консоли логов
  - Отображение событий в реальном времени
  - Фильтрация по типу событий
  - Прокрутка логов

- **SettingsEditor**: Редактор конфигурации
  - Редактирование настроек приложений
  - Добавление/удаление приложений
  - Сохранение/загрузка конфигурации

- **SystemTray**: Интеграция с системным треем
  - Иконка в трее
  - Контекстное меню
  - Сворачивание/разворачивание окна

## Технологии

- **VL.ImGUI**: Библиотека для создания UI в VVVV Gamma
- Реактивная связь с ViewModel через Observable/Channels

## Примечание

Файлы `.vl` с UI патчами будут созданы через редактор VVVV Gamma. Здесь будут храниться только описания и документация.
