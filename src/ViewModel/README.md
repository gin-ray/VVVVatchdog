# ViewModel

Эта папка содержит логику представления (ViewModel) в архитектуре MVVM.

## Компоненты

- **WatchdogViewModel**: Главный ViewModel для управления состоянием всех отслеживаемых приложений
  - Управление списком приложений
  - Реактивные каналы для обновления UI
  - Логика перезапуска с учётом ограничений (защита от boot loop)
  - Обработка событий от ProcessHelper

- **AppViewModel**: ViewModel для управления состоянием одного приложения
  - Отслеживание состояния конкретного процесса
  - Обработка событий запуска/остановки
  - Управление перезапусками

## Технологии

- Reactive Extensions (Observable/Channels) для реактивного управления состоянием
- Интеграция с Model и Utils слоями
- Связь с View через реактивные потоки данных

## Примечание

Файлы `.vl` с реализацией ViewModel будут созданы через редактор VVVV Gamma. Здесь будут храниться только описания и документация.
