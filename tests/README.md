# Tests

Эта папка содержит тестовые патчи для проверки логики без UI.

## Назначение

Тестовые патчи позволяют:
- Проверять работу отдельных модулей изолированно
- Тестировать логику без необходимости запускать полный UI
- Отлаживать компоненты Model, ViewModel и Utils
- Проверять сценарии: зависание процесса, падение, перезапуск

## Структура тестов

Тесты будут организованы по модулям:
- Тесты для Model (валидация данных)
- Тесты для ViewModel (логика перезапуска, обработка событий)
- Тесты для Utils (ProcessHelper, XMLSerializer, OSCService)
- Интеграционные тесты

## Примечание

Тестовые `.vl` патчи будут созданы через редактор VVVV Gamma по мере разработки модулей.
